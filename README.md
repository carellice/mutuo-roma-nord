# Mutuo Roma Nord

Simulatore di mutuo prima casa per le zone di Roma nord (Porta di Roma, Casal Boccone, Bufalotta, Fidene, Colle Salario, Settebagni, Serpentara): rata, spese accessorie, prezzo massimo approvabile, scenari, confronto fisso/variabile e offerte delle banche (dati di ottobre 2026).

Pagina singola statica (`index.html`), pubblicata con GitHub Pages.

Non è consulenza finanziaria: le cifre sono simulazioni su dati pubblici.
